# 록맨 에그제 4 한글 패치

> **⚠ 알려진 문제 (v0.9)** — 아래 문제가 확인되어 고치는 중입니다.
> - 칩 폴더 편집(FOLDER EDIT) 화면에서 칩 이름 글자가 깨질 수 있습니다.
> - 메뉴(PET 메뉴·내비게이터 선택지)와 키 아이템 이름이 일본어로 남아 있고, 대사에 끼워 넣어지는 아이템 이름(예: 「デカオのPコード」)도 일본어로 나옵니다.
> - PET 화면의 장소 이름 칸이 깨져 보입니다.
>
> 고친 판을 올리면 여기에 알리겠습니다.

록맨 에그제 4 **토너먼트 블루문 / 레드선** (일본판, GBA) 한글 패치입니다.

---

## 적용 방법

패치는 **xdelta** 파일입니다. 본인이 가진 ROM 에 직접 적용해서 쓰세요.
**이 배포본에는 ROM 이 들어 있지 않고, 앞으로도 넣지 않습니다.**

1. [xdelta UI](https://www.romhacking.net/utilities/598/) 같은 패치 도구를 준비합니다.
2. **Patch** 에 아래 xdelta 파일, **Source File** 에 원본 ROM 을 지정합니다.
3. 나온 파일을 에뮬레이터나 플래시카트에 올립니다.

| 판 | 패치 파일 | 원본 ROM SHA-256 |
|---|---|---|
| 블루문 | `RockmanEXE4_BlueMoon_JP_KR_v0.9.xdelta` | `f976a84ef226e47d4a65695052da09b415867b01586dd74bbb1c289a6f607b63` |
| 레드선 (Rev 1) | `RockmanEXE4_RedSun_JP_Rev1_KR_v0.9.xdelta` | `1904692bc383fc2cb7e1d81e1c80bf2d8c616c0d1b1d396c689f71b49a2e3188` |

원본 ROM 의 해시가 위와 다르면 적용되지 않습니다. 레드선은 **Rev 1** 이어야 합니다.

적용 후 나오는 ROM 의 SHA-256:

| 판 | 패치 적용 결과 SHA-256 |
|---|---|
| 블루문 | `a66858e3cf0789f3097355d7e68b2f411ef2db991b0d3edb18f47980881fadd1` |
| 레드선 | `5f21bc817bc953537d04115babda688eeabd7ea675a645c62b3fb7f274192c18` |

패치 파일은 만든 뒤 **원본에 다시 적용해서 위 해시가 나오는지 확인**한 것만 넣었습니다.

## 무엇이 번역됐나

- **본편 대사 22,771 / 22,919줄 (99.4%)** — 스토리·NPC 대사·메일·조사 문구 등.
  남은 148줄은 게임이 읽지 않는 곳입니다(디버그 메뉴 아카이브 1개와 참조가 없는 아카이브 2개).
- **칩 이름·칩 설명** — 칩 폴더, 데이터 라이브러리, 전투 칩 선택창·전투 중 표시
- **메뉴** — 오프닝 메뉴, 폴더·라이브러리 설명 등
- 두 판본에서 원문이 다른 대사는 판본마다 따로 번역했습니다.
- 용어는 용어집(인물·지명·칩 이름)으로 묶어, 같은 이름이 배치마다 달라지지 않게 검사했습니다.

## 아직 안 된 것 · 알려진 문제

이 패치는 **전체 통과 플레이 검증이 끝나지 않았습니다.** 그래서 v1.0 이 아니라
v0.9 프리릴리즈입니다.

- **게임을 처음부터 끝까지 플레이하며 확인하지 않았습니다.** 모든 대사는 폭(한 줄 180픽셀,
  3줄)·인코딩·용어 게이트를 통과했고, 게임 자체의 대사 렌더러로 대사를 강제로 그려 보는
  자동 검사에서 블루문 대사의 약 83%가 ROM 글꼴과 픽셀 단위로 정확히 일치했습니다.
  나머지는 이름이 끼워 넣어지는 줄·다른 창에 그려지는 줄처럼 자동 판정이 못 잡는 경우가
  대부분이지만, 전부 눈으로 확인한 것은 아닙니다.
- **실기(GBA 하드웨어·My Boy! 등)에서는 확인하지 않았습니다.** 에뮬레이터(Mesen)에서만
  확인했습니다.
- 그림으로 들어간 글자(타이틀 로고 등)는 번역하지 않았습니다.
- 번역 검수를 다른 사람이 따로 보지 않았습니다.

문제를 발견하면 [Issues](https://github.com/Einbroch/rockman-exe4-kr-patch/issues) 에
장면 설명이나 스크린샷과 함께 알려 주세요.
