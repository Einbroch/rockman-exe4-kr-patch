# 록맨 에그제 4 한글 패치 v0.9.3

록맨 에그제 4 **토너먼트 블루문 / 레드선** (일본판, GBA) 한글 패치입니다.

---

## 적용 방법

패치는 **xdelta** 파일입니다. 본인이 가진 ROM 에 직접 적용해서 쓰세요.
**이 배포본에는 ROM 이 들어 있지 않고, 앞으로도 넣지 않습니다.**

1. [xdelta UI](https://www.romhacking.net/utilities/598/) 같은 패치 도구를 준비합니다.
2. **Patch** 에 아래 xdelta 파일, **Source File** 에 **원본 일본판 ROM** 을 지정합니다.
   (v0.9 를 적용한 ROM 이 아니라 원본에 적용해야 합니다.)
3. 나온 파일을 에뮬레이터나 플래시카트에 올립니다.

| 판 | 패치 파일 | 원본 ROM SHA-256 |
|---|---|---|
| 블루문 | `RockmanEXE4_BlueMoon_JP_KR_v0.9.3.xdelta` | `f976a84ef226e47d4a65695052da09b415867b01586dd74bbb1c289a6f607b63` |
| 레드선 (Rev 1) | `RockmanEXE4_RedSun_JP_Rev1_KR_v0.9.3.xdelta` | `1904692bc383fc2cb7e1d81e1c80bf2d8c616c0d1b1d396c689f71b49a2e3188` |

원본 ROM 의 해시가 위와 다르면 적용되지 않습니다. 레드선은 **Rev 1** 이어야 합니다.

적용 후 나오는 ROM 의 SHA-256:

| 판 | 패치 적용 결과 SHA-256 |
|---|---|
| 블루문 | `6ed7e9bef94d6e31223e9c78dca529dbf07d9c2d82be486834fff9c06dc83e06` |
| 레드선 | `653b24b7d6a3fb616e1bc4836c0ca25808f570fb3831504c58e97e8de2757b03` |

패치 파일은 만든 뒤 **원본에 다시 적용해서 위 해시가 나오는지 확인**한 것만 넣었습니다.

## v0.9.3 에서 바뀐 것 (v0.9.2 대비)

- **칩 설명 전체 번역.** 지금까지 칩 설명은 10개만 한국어였습니다. 칩 365개 설명을 모두 번역해
  상점·칩 폴더·데이터 도감·커스텀 화면에 나오게 했습니다.
- **상점 칩 목록**의 칩 이름을 한국어로.
- **필드에서 얻는 칩 이름**(「캐논 A」 획득!! 등 대사 속 칩 이름)을 한국어로.
- **타운 에리어 넷 내비 대사**(81줄)가 통째로 빠져 있던 것을 번역.

## v0.9.2 에서 바뀐 것 (v0.9.1 대비)

- **아이템 획득 등에서 게임이 멈추던 문제 수정.** 한국어 대사가 원본보다 길어져, 게임이 대사를 풀어 놓는
  고정 메모리 칸(지역 대사 3칸·메일 본문 등)을 넘쳐 다음 칸을 덮는 경우가 있었습니다(mGBA 「Jumped to invalid address」).
  칸을 넘는 대사는 ROM 에서 바로 읽도록 바꿔, 원본에 없던 넘침이 지역·진행도 조합 21,888개 중 0개가 되었습니다.
- **전투 결과 화면** 그림 글자: 딜리트 타임 / 버스팅 레벨.

## v0.9 에서 바뀐 것

- **칩 폴더 편집 화면 글자 깨짐 수정.** 칩을 옮길 때 칩 그림이 한글 글자를 덮던 문제를 고쳤고,
  칩 이름 전부(내비 칩·기가 칩 포함)가 폴더·팩 목록에 한글로 나옵니다.
- **메뉴·폴더·PLACE 글자를 크게.** 메뉴 칸 글자를 록맨 에그제 1 한국어판 글리프(8×16)로 바꿔
  에그제 3 한글 패치와 같은 크기로 보입니다.
- **PET 메뉴 그림 글자 번역.** 칩 폴더 / 서브칩 / 데이터도감 / 록맨 / E메일 / 키 아이템 / 통신 / 세이브
  (가는 글씨, 칸 가운데 정렬), 록맨 상태 화면의 탭(록버스터 / 폴더 / 프로그램).
- **칩 폴더 정렬(SORT) 메뉴 번역.** ID / 가나다순 / 코드 / 공격력 / 속성 / 장수 / 칩 용량.
- **전투 화면 번역.** 적 이름(메트올 등 243개), 커스텀 화면 패널(칩데이터를 송신합니다 / 선택된 칩 없음 /
  칩 폴더를 셔플!), 전투 중 칩 이름 표시.
- **메일 본문 깨짐 수정.** 번역으로 길어진 메일 본문이 게임 메모리에서 메일 머리 자리와 겹쳐
  뒤쪽 메일 글자가 깨질 수 있었습니다. 메일 머리 자리를 옮겨 고쳤습니다.
- **새로 번역한 곳:** 메일 보낸이·받는이·제목, 통신(넷배틀·비교·트레이드·대기실) 메뉴,
  록맨 상태(어택/래피드/차지 LV, 용량·칩 장수), 세이브 화면의 칩 장수, 데이터 도감 탭, 키 아이템 이름, 장소 이름,
  폴더 이름, 내비 커스터마이저 프로그램 이름, 스태프 크레딧, 「BUG PIECE 0개」 등.
- **추가 번역:** 서브칩 설명, 차지샷 종류, 대전 승리 수·대표전·프로그램, PET 메시지 라벨,
  RUN 확인·HP 최대 표시, 대사 속 퀴즈 답 단어 47개 등 126곳.
- **게시판(BBS) 글 목록** 6개 게시판 102행(글쓴이·제목), **트레이닝 메뉴**(트레이닝 / 통신대전 / 설명),
  **상점 재고 개수 단위**(「コ」→「개」).
- **데이터 도감 P.A 메모** 조합식 39개(칩 이름은 칩 폴더 표기), P.A 메모 탭의 「パターン」 그림 글자 → 「패턴」.
- **타이틀 메뉴** 그림 글자: 새로하기 / 이어하기(「N회차 이어하기」, 「오퍼레이션배틀」 포함).
- **지도 지역 이름** 10개(아키하라 마을·전기가·덴산 돔·셰로 카스티요·공항·일본·아메로파·아지나·아프리크·샤로).

## 무엇이 번역됐나

- **본편 대사 22,771 / 22,919줄 (99.4%)** — 스토리·NPC 대사·메일·조사 문구 등.
  남은 148줄은 게임이 읽지 않는 곳입니다(디버그 메뉴 아카이브 1개와 참조가 없는 아카이브 2개).
- **칩 이름·칩 설명** — 칩 폴더, 데이터 라이브러리, 전투 칩 선택창·전투 중 표시

## 아직 안 된 것 · 알려진 문제

이 패치는 **전체 통과 플레이 검증이 끝나지 않았습니다.** 그래서 아직 v1.0 이 아닙니다.

- **게임을 처음부터 끝까지 플레이하며 확인하지 않았습니다.** 메뉴 화면은 레드선 초반 세이브로,
  오프닝은 두 판본 모두 자동 경로로 확인했습니다. 블루문은 세이브 화면 확인을 하지 않았습니다.
- **아직 일본어로 남은 곳:** 지하철 이동 지도의 지역 이름(그림 글자로 보임), 타이틀 로고 등 일부 그림 글자,
  통신(트레이드 등) 화면 일부의 칩 이름.
- **화면으로 아직 못 본 것:** 지도 지역 이름, 「N회차 이어하기」·「오퍼레이션배틀」 타이틀 항목, P.A 메모 조합식(세이브에 메모가 없음), 게시판 글 목록, 상점 개수 표시, 트레이닝 메뉴, 스태프 크레딧, 내비 커스터마이저 프로그램 이름, 통신 케이블 연결 화면.
- **실기(GBA 하드웨어·My Boy! 등)에서는 확인하지 않았습니다.** 에뮬레이터(Mesen)에서만 확인했습니다.
- 번역 검수를 다른 사람이 따로 보지 않았습니다.

문제를 발견하면 [Issues](https://github.com/Einbroch/rockman-exe4-kr-patch/issues) 에
장면 설명이나 스크린샷과 함께 알려 주세요.
